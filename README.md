# PickyBooking

Free WordPress.org edition of PickyBooking — visual floor-plan bookings with bookable items, shortcode embed, and email notifications.

## Requirements

- WordPress 5.8+
- PHP 7.4+

## Documentation

Open `docs/index.html` in the browser or visit **wp-admin → PickyBooking → Documentation**.

Online after install:

```
https://YOUR-SITE/wp-content/plugins/pickybooking/docs/
```
