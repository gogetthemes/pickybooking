Free vs Pro at a glance

Core builder (bookable items), shortcode, emails, and presets are free in Lite. Payments, decorative layers, SMS, AI, CRM/automation, avatars, JSON import/export, and Elementor are Pro. Full matrix: Free vs Pro.

1. Visual layout builder Core

Draw a real floor/area plan that guests interact with on the front end.

1.1 Bookable items

Anything guests can reserve on the map.

  • Square items — rectangular tables, desks, rooms, booths.
  • Circle items — round tables, stools, pods.
  • Capacity (max persons) — used in capacity booking mode and party-size logic.
  • Seats count — optional seat badge on the map.
  • Custom ID / label — public identifier (e.g. L12, Table 4) and display name.
  • Color or image fill — brand the plate; images cover the tile.
  • Opacity — soft overlays for zones still bookable.

1.2 Decorative / non-bookable layers

Help guests understand the space; they never open a booking form.

  • Walls — corridors, stage edges, barriers; free rotation.
  • Text — section titles (“Bride’s Family”, “Zone A”).
  • Shapes — rectangles, rounded, circles, triangles for zones.
  • Icons — bathroom, bar, exit, VIP, etc. from the icon catalog.

1.3 Transform & canvas

  • Drag position — place items in px; front end matches builder 1:1.
  • Resize — width/height handles.
  • Rotate Z — flat rotation for arcs and angled rows.
  • 3D tilt (X / Y) — perspective on the plate; avatars follow the same transform.
  • Layer order — bring to front / send to back.
  • Duplicate — Ctrl/Cmd+D for quick grids.
  • Undo / zoom / canvas size — edit large venues comfortably.

1.4 Services library

  • Named services with price & currency — shown in the booking popup.
  • Per-item service binding — only relevant add-ons for that seat/table.
  • Add-ons of parent services — gated extras.
  • Service icons — visual chips in the guest UI.
  • AI fill — draft service copy when AI keys are configured.

1.5 Layout appearance & modes

  • Canvas background — image/color/fit; transparent canvas for branded pages.
  • Toggle seats, IDs, labels, item fill — declutter or emphasize.
  • Booked avatars — show guest photos on reserved seats (same tile size as empty seats).
  • Multi-select — guests pick several items in one checkout.
  • Event schedule — one fixed date/time (calendar hidden) for ceremonies/matches.
  • Per-layout wizard override — Classic / Smart / Smart Map / Simple.
  • AI layout draft — generate a starting floor plan from a prompt.

2. Guest booking experience Core

How visitors reserve on your WordPress page.

2.1 Wizard modes

  • Classic — pick item on map → then date/time/details.
  • Smart — date & time first → only available items → details.
  • Smart Map — map stays visible; sticky dock for date/time; live availability on seats; selection tray + Book.
  • Simple — no map pick; date/time/details; auto-assign first free item.

2.2 Map interaction

  • Live availability — booked/blocked seats disabled for the selected slot.
  • Hover badges — ID and capacity without cluttering the idle map.
  • Enter animation — staggered reveal of bookable items on load.
  • Mobile behavior — keep scaled map, hide map, or use dropdown — site-wide or per rules.
  • Account bar — login / book as guest; logged-in avatars on seats when enabled.

2.3 Form & checkout

  • Date & start time — within work days and horizon.
  • Optional end time — variable session length.
  • Party size / seats — respects capacity mode.
  • Contact fields — name, phone, email (toggle visibility in Main).
  • Services chips — extras from the layout library.
  • Multi-item cart — parent order + child bookings.
  • Book Now / Pay & Book — CTA switches when payments are required.

3. Availability & booking engine Core

3.1 Modes

  • Exclusive — one booking fully occupies the item for that time range (tables, rooms, courts).
  • Capacity — shared resource until max persons filled (tours, classes, hot desks).

3.2 Time rules

  • Weekly hours — per weekday on/off + open/close.
  • Split windows — second daily range (e.g. lunch closed).
  • Days ahead — how far into the future guests may book.
  • Default duration — length when end time is not chosen.
  • Buffer / turnover — padding before/after so slots do not collide.
  • Slot hints AJAX — suggests workable times for the guest UI.

3.3 Data model

  • Layouts CPT — floor plans + meta.
  • Bookings CPT — single reservation (or child of an order).
  • Orders CPT — parent for multi-item checkouts.
  • Statuses — Requested, Reserved, Canceled (cascade on orders).
  • Failed payment init — does not permanently block the map.

4. Admin operations

4.1 Bookings

  • Unified list — reservations and paid orders in one place.
  • Inline status — change Requested / Reserved / Canceled with feedback.
  • Guest & payment columns — date, time, people, services, payment link.
  • New booking highlights — mark newly arrived rows as seen.

4.2 Calendar

  • Layout filter — focus one venue map.
  • Embedded editor — open booking details without leaving the calendar.

4.3 Layouts library

  • User layouts gallery — open builder, duplicate, delete.
  • Bundled presets — restaurant, wedding, cinema, coworking, beauty, EV, football…
  • Import / export JSON — clone between sites.
  • Shortcode copy — one click from the card.

5. Payments

  • Deposit toggle — require money before confirmation.
  • Amount source — fixed, from services, or services-or-fixed.
  • Stripe Checkout — hosted payment + return handler.
  • WooCommerce — create order/fee; use Woo gateways (incl. Stripe/PayPal via Woo).
  • Currency — display and charge currency.

6. Communications

  • Admin email — wp_mail on new booking.
  • Customer email — optional confirmation.
  • Thank-you / success copy — after submit.
  • Staff SMS — Vonage/Nexmo to a destination phone.
  • AI copy helpers — draft form/service text when AI is connected.

7. Integrations & automation

  • HubSpot — contacts / optional deals.
  • Mailchimp — audience subscribe/update.
  • n8n / Zapier / Make — JSON webhooks with HMAC secrets.
  • Google Calendar — service-account events (+ attendees option).
  • AI providers — Groq (default) or OpenAI for layout draft & copy.

8. Embeds & page builders

  • Shortcode — [pickybooking id="LAYOUT_ID"].
  • Elementor — Layout Navigator widget.
  • WPBakery / Visual Composer — mapped shortcode params.
  • Multiple maps per page — each instance scoped in JS.

9. Theming & front-end polish

  • Layout Colors tab — map / datepicker / form palette for the public shortcode.
  • Container alignment — how the booking block sits in the page.
  • Demo seeding — sample layouts, demo guests, avatar occupancy for showcases.
