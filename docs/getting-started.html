Getting started

Stage-by-stage path from install to first live booking. Follow this order — each step unlocks the next.

Important path ~30–60 minutes first setup

Stage 1 — Install

  1. Upload & activate Install the PickyBooking plugin in WordPress → Plugins. On activation, default settings are written to picky_settings.
  2. Open the dashboard In wp-admin find the PickyBooking menu. All work happens inside one settings shell with tabs: Bookings, Calendar, Layouts, Main, Work Days, and more.

Stage 2 — Business rules (do this before styling)

Why first?

Wrong hours or exclusive/capacity mode break guest availability even if the map looks perfect.

  1. Main settings Set singular/plural item names (Table/Tables, Seat/Seats…), booking window (days ahead), default duration, buffer between bookings, exclusive vs capacity, wizard default, form fields, mobile map behavior.
  2. Work Days Enable each weekday, open/close times, optional second window (lunch break / double shift).
  3. Form & Emails Thank-you text, admin email, optional customer confirmation email, consent checkbox copy.

Stage 3 — Build a layout

  1. Layouts → New or preset Start blank or import a bundled preset (restaurant, wedding, cinema, coworking, beauty, EV, football…).
  2. Place bookable items Squares and circles are bookable. Walls, text, shapes, icons are visual only. Set capacity, ID, label, color/image, services.
  3. Rotate / 3D if needed Use Z-rotate for arcs and rows; X/Y tilt for perspective. Guest avatars follow the same angle.
  4. Services library Define paid/optional services and assign them per item. Add-ons can depend on parent services.
  5. Appearance & wizard override Canvas background, show seats/IDs/labels/avatars, multi-select, event (one-time) mode, per-layout wizard (Classic / Smart / Smart Map / Simple).
  6. Save & copy shortcode Copy [pickybooking id="…"] from the layout card or builder badge.

Stage 4 — Optional money & CRM

  • Payments — deposit on/off; Stripe Checkout or WooCommerce; amount from fixed price, services, or both.
  • SMS — Vonage/Nexmo alert to staff on new booking.
  • Integrations — HubSpot, Mailchimp, n8n, Zapier, Make, Google Calendar, AI (Groq/OpenAI).

Stage 5 — Publish & test

  1. Add shortcode to a page Or drop the Elementor Layout Navigator / WPBakery map.
  2. Book as a guest Desktop and mobile. Check unavailable seats, multi-select tray, payment return, emails.
  3. Confirm in admin Bookings list and Calendar show the reservation. Change status: Requested → Reserved / Canceled.

Stage 6 — Day-to-day operations

Bookings tab

Unified list of reservations and multi-item orders. Status, payment, guest data, new-row highlights.

Calendar tab

Visual day/week view filtered by layout. Open a booking and edit without leaving the calendar.
