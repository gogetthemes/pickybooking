FAQ

Short answers to common setup and product questions.

Lite vs Pro — what do I need?

Lite (WordPress.org): bookable floor plans, shortcode booking, email alerts. Pro: payments, decorative layers, SMS, AI, CRM/webhooks, avatars, JSON import/export, Elementor. See Free vs Pro.

Can I run Lite and Pro together?

No. They share the same booking data types. Activate only one edition per site.

Why is a seat shown as unavailable?

Another booking overlaps the slot (including buffer), the weekday is closed, the date is outside “days ahead”, or (in capacity mode) remaining persons are zero.

Exclusive vs capacity — which do I need?

Exclusive for one party per table/room/court. Capacity when many guests share the same resource until max persons is reached.

Avatars look larger than empty seats

They should not — avatars fill the same bookable tile. Hard-refresh the page (and clear caches). Rotated seats: avatars inherit the same angle.

Where do I find the layout ID?

Layouts gallery / builder shortcode badge / URL when editing. Use that number in [pickybooking id="…"].

Can one page have two maps?

Yes. Place two shortcodes with different layout IDs.

Do I need WooCommerce?

Only if you choose the WooCommerce payment provider. Stripe Checkout works without Woo. Free bookings need neither.

How do I clone a layout to another site?

Import / Export tab → export JSON → import on the other install. Or duplicate inside the same site from Layouts.

Where are the step-by-step tutorials?

Sidebar How-to guides plus Industry recipes and Troubleshooting. Also: Avatars, Import/Export, AI in builder.
