How to set up services & prices

Create a Services Library for the layout, bind services to seats/tables, and control what guests see in the booking form.

How-to Per-layout library

What “services” are

Extras or products tied to a booking: champagne, massage upgrade, parking pass, meeting-room AV pack. They appear as chips in the guest form. Prices can feed deposits when Payments use “services” or “services or fixed”.

Step 1 — Open Services Library

  1. Edit the layout Layouts → open the map in the builder.
  2. Open Services Library Use the layout’s Services / library panel (not a global Settings tab). Each layout has its own list.

Step 2 — Add a service

  1. Name & description Guest-facing title (e.g. “Birthday cake”) and short description.
  2. Price & currency Numeric price; currency should match what you use in Payments.
  3. Icon (optional) Pick from the booking icons catalog so chips look clear on mobile.
  4. Add-on of (optional) Make this service available only when a parent service is selected (e.g. “Extra towels” only with “Spa package”).
  5. Save the library Then save the layout so bindings persist.
AI helper

If Integrations → AI is configured (Groq/OpenAI), you can draft service copy from a short prompt — always review prices before publishing.

Step 3 — Bind services to items

  1. Select a bookable item Square or circle on the canvas.
  2. Choose available services Multi-select chips from the library. Only bound services appear when that seat/table is booked.
  3. Repeat by zone VIP seats → premium services; standard seats → basic list. Duplicate items keep bindings when you copy after binding.

Step 4 — Check the guest form

  • Publish / refresh the shortcode page.
  • Select an item that has services → you should see the chips.
  • Select an item with no services → no service section (or empty).
  • If payments use service totals, pick paid services and confirm the Pay & Book amount.

Common setups

Restaurant

Decor, cake, wine package — bind to larger tables only.

Beauty / clinic

Treatment types as services on each chair/room; add-ons as children.

Coworking

Day pass extras, locker, parking — bind to desks vs meeting rooms differently.

Event / wedding

Optional dinner upgrade or shuttle — bind to guest seats, not altar/stage decor.
