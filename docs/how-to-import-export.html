Import / Export layouts

Clone floor plans between staging and production, duplicate presets, and move services with the layout JSON.

How-to Import / Export tab

Pro This guide describes PickyBooking Pro capabilities. They are not included in PickyBooking — see Free vs Pro.

What gets exported

Layout JSON typically includes elements (positions, types, colors, rotation), services library, appearance flags (IDs, labels, avatars…), wizard/event/multi-select meta, and canvas settings — not live bookings or payment credentials.

Export a layout

  1. Open the layout Layouts gallery → open in the visual editor, or use Export on the layout card if shown.
  2. Click Export In the builder top bar (as described on the Import / Export tab). Download / copy the JSON file.
  3. Store safely Version the file with the layout name and date (e.g. dining-main-2026-08.json).

Import into this site

  1. PickyBooking → Import / Export Tab 10 in the settings shell.
  2. Optional title Name the new layout (default “Imported Layout”).
  3. Paste JSON or upload the file Submit the import form. On success you are taken into the builder for the new picky_layout post.
  4. Review & save Check services bindings, appearance toggles, and shortcode ID (new ID ≠ old site).
Invalid JSON

Import errors if the file is empty, not JSON, or has no valid elements. Re-export from the source layout; do not hand-edit IDs unless you know the schema.

Clone across environments

  1. Export on staging After the map looks right.
  2. Import on production Same plugin version recommended.
  3. Re-publish the page New layout ID → update [pickybooking id="…"] (or Elementor widget).
  4. Re-check site settings Work Days, Payments, Integrations are site-wide — they do not travel inside layout JSON.

Same-site shortcuts

  • Duplicate in the Layouts gallery — quick clone without leaving the site.
  • Bundled presets — import from the library gallery (restaurant, wedding, cinema…).
