How to build a layout

Practical walkthrough: create a floor map, place seats/tables, set appearance, and publish with a shortcode.

How-to ~15–40 minutes

Before you start

  • In Main, set item names (Table/Seat…), exclusive vs capacity, and default wizard.
  • In Work Days, set open hours so the map has bookable slots.
  • Have a rough sketch of the room (photo, floor plan, or napkin drawing).

Step 1 — Create or import

  1. Open Layouts wp-admin → PickyBooking → Layouts.
  2. Pick a starting point New layout for a blank canvas, or open a bundled preset (Restaurant, Wedding, Cinema, Coworking, Beauty, EV, Football) and customize.
  3. Name it Use a clear title guests never see — e.g. “Main dining — evening”. Guests only see the published page.

Step 2 — Place bookable items

  1. Add squares or circles These are the only bookable types. Drag onto the canvas; resize with handles.
  2. Set identity Select an item → set Custom ID (e.g. T12, L3) and optional Label. Turn “show ID” on if guests should see the code on the map.
  3. Set capacity Max persons matters in Capacity mode and when party size is enabled. For exclusive tables, keep it as the table size for guest guidance.
  4. Style the plate Solid color or custom image. Opacity for soft zones. Corner radius if you want softer seats.
  5. Rotate / 3D if needed Use Z-rotate for angled rows or arcs. Use the 3D pad (X/Y) for perspective. Guest avatars follow the same angle.
  6. Duplicate grids Place one seat correctly → Ctrl/Cmd+D → move copies into rows. Faster than drawing each one.
Tip

Keep seats in one grid the same size. Different sizes are fine for VIP / stage, but random sizes look like bugs.

Step 3 — Add non-bookable helpers

Walls

Stage edge, aisle barriers, room outline. Freely rotatable.

Text

Section titles: “Bar”, “Bride’s Family”, “Zone A”. Guests cannot book these.

Shapes

Rugs, dance floor, zones behind seats.

Icons

Restroom, exit, bar, VIP — from the icon catalog.

Step 4 — Layout settings (right panel / layout tabs)

Appearance

  • Canvas background image or color (or transparent for branded pages).
  • Show / hide: seat dots, ID badges, labels, item fill, booked avatars.

Wizard override

  • Leave “site default”, or force Classic / Smart / Smart Map / Simple for this map only.

Multi-select

  • On = guests can pick several seats/tables in one checkout (creates an order + child bookings).

Event schedule

  • For a ceremony or match: switch to one-time event, set date + time, optional label on the booking bar. Calendar picker is hidden.

Step 5 — Save & publish

  1. Save the layout Use the builder save control. Confirm the layout appears in the Layouts gallery.
  2. Copy the shortcode From the gallery card or builder badge: [pickybooking id="123"] (use your real ID).
  3. Paste on a page Or use Elementor Layout Navigator / WPBakery map element.
  4. Test as a guest Desktop + mobile. Try a free seat, a booked seat, and (if enabled) multi-select.
