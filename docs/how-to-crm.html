How to integrate CRM & automation

Send successful bookings to HubSpot, Mailchimp, Google Calendar, or webhooks (n8n / Zapier / Make). All live under the Integrations tab.

How-to Integrations tab

Pro This guide describes PickyBooking Pro capabilities. They are not included in PickyBooking — see Free vs Pro.

Shared requirements

  • Booking must complete successfully (including payment return if Pay & Book).
  • Show email and/or phone on the guest form (Main tab) — CRMs need an identifier.
  • Each section shows a short connection strip + Test where available — use it after saving keys.
Event name for webhooks

Outbound JSON uses event pickybooking.booking_created plus guest, reservation, payment, and HubSpot IDs if synced.

HubSpot CRM

  1. Create a private app / access token In HubSpot: Development → Legacy apps (or a developer project). Scopes for contacts (and deals if you sync deals).
  2. Integrations → HubSpot Enable “Send new bookings to HubSpot CRM”. Paste the access token.
  3. Optional deals Turn on “Create a HubSpot deal for each booking”. Optionally paste pipeline / stage IDs; leave blank to auto-pick the first pipeline and stage.
  4. Test Connection Then place a real booking with email/phone and confirm the contact (and deal) in HubSpot.

Mailchimp

  1. API key + Audience ID From Mailchimp account → API keys and audience settings.
  2. Enable in Integrations Paste key and audience. Guests are added/updated as subscribers on successful booking.
  3. Test Connection Verify credentials, then run a live booking with email filled.

n8n / Zapier / Make (webhooks)

  1. Create a Catch Hook / Webhook In your automation tool, create an HTTPS webhook URL.
  2. Paste URL in Integrations Use the matching section (n8n, Zapier, or Make). Optional HMAC secret if the tool supports signed payloads.
  3. Map fields in the tool Subscribe to pickybooking.booking_created. Typical fields: guest name/email/phone, date/time, item IDs, services, payment status, layout id.
  4. Trigger a test booking Confirm the automation run and fix field mapping before going live.

Good for

Slack/Telegram alerts, Google Sheets rows, custom CRM, SMS beyond Vonage, follow-up sequences.

Tip

Use a staging layout shortcode for the first webhook tests so production guests are not affected.

Google Calendar

  1. Service account JSON Create a Google Cloud service account with Calendar API enabled. Share the target calendar with the service account email.
  2. Paste JSON in Integrations Enable Google Calendar sync. Optionally invite the guest as attendee when email is present.
  3. Test Book once and confirm the event appears on the calendar for the reservation time range.
