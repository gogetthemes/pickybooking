How to set up payments

Turn free bookings into deposits with Stripe Checkout or WooCommerce. Guests see Pay & Book when payment is required.

How-to Payments tab

Pro This guide describes PickyBooking Pro capabilities. They are not included in PickyBooking — see Free vs Pro.

Choose a provider

ProviderUse when
None Free reservations only — CTA stays “Book Now”.
Stripe Checkout You want hosted Stripe without WooCommerce. Paste publishable + secret keys.
WooCommerce You already sell with Woo and want its gateways (Stripe/PayPal via Woo, etc.).

Step-by-step (Stripe)

  1. Open Payments PickyBooking → Payments.
  2. Enable deposit Turn deposits on so payment is required to complete the booking flow.
  3. Amount source Fixed = same deposit every time. Services = sum of selected services. Services or fixed = services when present, otherwise fixed.
  4. Currency Must match your Stripe account and service prices.
  5. Provider = Stripe Paste test keys first. Save.
  6. Test end-to-end Public page → select seat → Pay & Book → complete Checkout → return → booking Reserved / paid in Bookings.
  7. Switch to live keys Only after a successful test. Keep a staging site for future experiments.

Step-by-step (WooCommerce)

  1. Install & configure Woo Enable the gateways you need under WooCommerce → Settings → Payments.
  2. Provider = WooCommerce In PickyBooking Payments. Set deposit / amount source / currency as above.
  3. Test Guest is sent through a Woo order/fee path; when Woo marks paid, the booking status updates accordingly.

Ops notes

  • Failed payment starts do not permanently block the map.
  • Refunds are handled in Stripe or Woo — change booking status separately if needed.
  • Service-based amounts need a filled Services Library.
