How to get emails & SMS notifications

Configure staff alerts, guest confirmations, thank-you copy, and optional Vonage SMS when a booking is created.

How-to Form & Emails · SMS

Pro This guide describes PickyBooking Pro capabilities. They are not included in PickyBooking — see Free vs Pro.

What fires when

ChannelWhenWho
Admin email Successful new booking (after form submit / paid flow completes) Address in Form & Emails
Customer email Same moment, if “Send confirmation to customer” is on Guest email field (must be visible & filled)
Staff SMS Same moment, if SMS is enabled Phone in SMS settings (Vonage/Nexmo)
Thank-you screen Immediately on the booking page Guest in browser

Admin + guest email

  1. Open Form & Emails PickyBooking → Form & Emails tab.
  2. Set admin email Where staff copies go. Use an inbox you monitor.
  3. Edit thank-you / success text Shown after Book / Pay & Book. Keep it short and include what happens next.
  4. Enable customer confirmation (optional) Turn on “Send confirmation to customer”. In Main, ensure the email field is shown on the form.
  5. Consent checkbox (if needed) Enable and write clear policy text for GDPR / marketing consent.
  6. Test deliverability Place a real test booking. If mail never arrives, install an SMTP plugin (WordPress wp_mail alone is often blocked on shared hosting).
Email field must be on

Customer email and HubSpot/Mailchimp matching need a filled email. Toggle the email field under Main → form visibility.

Staff SMS (Vonage / Nexmo)

  1. Open SMS tab PickyBooking → SMS.
  2. Enable send SMS Turn the feature on.
  3. Paste API key & secret From your Vonage/Nexmo dashboard. Save — the plugin checks balance when credentials are saved.
  4. Destination phone Staff number that should get “new booking” alerts (E.164 format recommended).
  5. Test Create a booking on the public map and confirm the SMS arrives within a minute.

Checklist when nothing arrives

  • Spam / junk folder for admin and guest addresses.
  • SMTP configured (recommended for production).
  • Guest email field shown and completed.
  • Booking actually completed (payment return finished if Pay & Book).
  • SMS: correct keys, funded Vonage account, phone format.
