Layout builder

Design the map guests will use. What you place here is what they click — keep bookable items clear and decorative layers secondary.

Open the builder

Go to Layouts → open an existing layout or create new / import a preset. The canvas editor loads with tools for elements, services, appearance, and AI draft.

Element types

TypeBookable?Use for
SquareYesTables, desks, rooms, booths
CircleYesRound tables, stools
WallNoStructure, stage, barriers
TextNoSection titles, wayfinding
ShapeNoZones, rugs, stages
IconNoRestroom, bar, exit, VIP

Editing a bookable item

  • Select → drag to move, handles to resize.
  • Rotate Z for angled rows; 3D pad for X/Y tilt.
  • Set custom ID, label, max persons, seats.
  • Pick color or upload a custom image.
  • Assign available services from the Services Library.
  • Duplicate (Ctrl/Cmd+D), reorder layers, delete.
Avatars & rotation

When a seat is booked and avatars are enabled, the photo fills the same tile and inherits the item’s rotation and 3D tilt — so curved rows stay visually consistent.

Layout-level settings

Services Library

Create priced services, descriptions, icons, parent/add-on links. Bind per item.

Appearance

Canvas bg, transparency, show/hide seats·IDs·labels·fill·avatars.

Wizard & event

Override site wizard; switch to one-time event date/time; multi-select on/off.

AI Layout

Describe the venue; get a draft plan (requires AI keys in Integrations).

Good practices

  1. Keep bookables uniform where possibleSame size for a grid of seats reads cleaner; intentional size differences are fine for VIP/stage seats.
  2. Label sections with Text, not bookable itemsGuests should not tap a decorative title expecting a booking.
  3. Test the shortcode after every major editSave → refresh the public page → try the intended wizard mode.
