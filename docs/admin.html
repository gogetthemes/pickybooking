Admin panel

Everything lives under the PickyBooking menu in wp-admin. Tabs below are listed in the order most operators use them.

Priority tabs

Bookings

Day-to-day inbox for reservations and multi-item orders.

  • Filter and open guest details.
  • Change status: Requested → Reserved / Canceled.
  • See payment state and linked Woo/Stripe references when used.
  • New rows can stay highlighted until marked seen.

Calendar

Visual schedule for a selected layout; open the booking editor in context.

Layouts

Gallery of your maps + bundled presets; open builder; duplicate; delete; copy shortcode; import from library.
