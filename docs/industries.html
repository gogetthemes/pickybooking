Industry recipes

Recommended settings per business type — labels, booking mode, wizard, duration, and extras. Start from a bundled preset when one exists.

Recipes Copy → adapt

How to use a recipe

  1. Import the closest presetLayouts gallery → Restaurant, Wedding, Cinema, Coworking, Beauty, EV, Football — or blank.
  2. Apply Main + Work DaysMatch the table below before polishing the map.
  3. Bind servicesSee Services & prices.
  4. Publish & testShortcode + one full guest journey on mobile.

Restaurant / cafe

  • Preset: Restaurant
  • Labels: Table / Tables
  • Mode: Exclusive
  • Wizard: Smart or Smart Map (busy nights → date/time first)
  • Duration: 1.5–2.5h + buffer for turnover
  • Show: ID + max persons on hover
  • Services: cake, wine, decor — bind to larger tables
  • Payments: optional deposit to cut no-shows

Wedding / ceremony

  • Preset: Wedding Ceremony
  • Labels: Seat / Seats
  • Mode: Exclusive
  • Wizard: Smart Map or Event schedule (fixed ceremony time)
  • Avatars: on — great for “who sits where”
  • Multi-select: optional for couples booking a block
  • Decor: Text + walls for aisle/altar; do not make them bookable

Cinema / auditorium

  • Preset: Cinema
  • Labels: Seat / Seats
  • Mode: Exclusive
  • Wizard: Classic or Smart Map; Event mode for a single screening
  • Map: walls for aisles; consistent seat size
  • Services: popcorn combo as optional chips

Coworking / hot desk

  • Preset: Coworking
  • Labels: Desk / Desks or Seat / Seats
  • Mode: Capacity (shared room) or Exclusive (private office)
  • Wizard: Smart — show only free desks for the slot
  • Party size: on when capacity mode
  • Services: locker, parking, day-pass upgrade
  • Horizon: larger days-ahead for weekly planning

Beauty / clinic / spa

  • Preset: Beauty Salon
  • Labels: Chair / Chairs or Room / Rooms
  • Mode: Exclusive
  • Wizard: Smart; split Work Days for lunch
  • Services: treatments as services per chair; add-ons as children
  • Form: consent checkbox + customer email on

Sports court / field

  • Labels: Court / Courts or Field / Fields
  • Mode: Exclusive
  • End time: show time-to for variable sessions
  • Payments: deposit recommended
  • Mobile: dropdown if only a few courts

EV charging / parking bays

  • Preset: EV Charging
  • Labels: Bay / Bays
  • Mode: Exclusive
  • Wizard: Smart Map
  • Duration: match typical charge window + buffer

Day tours / classes / hotel

  • Tours / classes: Capacity + party size; Smart wizard; duration = leg/session length
  • Hotel / B&B: Exclusive rooms; longer duration / end time; larger days-ahead; email + optional deposit
