Troubleshooting

Symptom → likely cause → what to check. Start here when the map or booking flow misbehaves.

Reference Ops checklist

Map & availability

All seats look free but booking fails / everything is grey

  • Work Days — weekday closed or outside open/close (and second window).
  • Days ahead — date past the horizon in Main.
  • Buffer / duration — slot overlaps another booking including turnover.
  • Exclusive vs capacity — capacity full for party size.
  • Event mode — layout locked to one date/time; wrong date selected.

Seat stays blocked after cancel

  • Confirm status is Canceled (not still Requested).
  • Multi-item order: cancel the parent order / all children.
  • Hard-refresh the public page (cache plugin / CDN).

Shortcode shows nothing / blank map

  • Wrong id — copy again from Layouts gallery.
  • Layout empty or not saved.
  • JS conflict — check browser console; disable other map/booking plugins temporarily.
  • Theme CSS hiding overflow — try transparent canvas off / another theme briefly.

Rotated seats / avatars look wrong size

  • Hard refresh (Cmd+Shift+R). Avatars should fill the same tile and follow rotation.
  • Uneven sizes in a grid usually come from the layout itself (different width/height in builder) — not from avatars.

Emails & SMS

Admin email never arrives

  • Correct address in Form & Emails; check spam.
  • Install SMTP (WP wp_mail often fails on shared hosting).
  • Booking must complete (including payment return if Pay & Book).

Guest confirmation missing

  • “Send confirmation to customer” on in Form & Emails.
  • Email field visible in Main and filled by the guest.
  • Same SMTP / spam checks as admin mail.

SMS silent

  • SMS tab enabled; Vonage key/secret saved; account funded.
  • Destination phone format (E.164).
  • Balance check on save — re-save credentials and watch for errors.

Payments

Pay & Book redirects but booking stays Requested / unpaid

  • Finish Stripe Checkout / Woo payment fully — abandon mid-checkout leaves unpaid holds.
  • Test vs live Stripe keys mismatch.
  • Woo: order status must reach paid; check Woo order notes.
  • Failed payment init should not permanently block the map — try another seat/time.

Amount is 0 or unexpected

  • Amount source = services but no services selected / library empty → see Services.
  • Currency mismatch between Payments and service prices.

CRM & webhooks

HubSpot / Mailchimp empty

  • Use Test Connection after saving keys.
  • Guest email (and phone for HubSpot matching) required — enable fields in Main.
  • Token scopes / audience ID wrong.

n8n / Zapier / Make never fires

  • HTTPS webhook URL pasted in the correct Integrations section.
  • Listen for pickybooking.booking_created.
  • HMAC secret must match if configured.
  • Trigger a completed booking (not a half-paid attempt).

Avatars & AI

  • No photos on booked seats — see Avatars & accounts (layout toggle + registration / user avatar).
  • AI draft fails — see AI in builder (provider key, model, rate limits).

Quick cache rule

After CSS/JS or layout save

Hard-refresh the public page and purge any page/CDN cache. Stale assets cause most “it still looks broken” reports.
