Integrations

Optional connections. Core booking works without any of these — enable only what your business needs.

Pro This guide describes PickyBooking Pro capabilities. They are not included in PickyBooking — see Free vs Pro.

Payments

  • Stripe Checkout — API keys in Payments; guest redirected to Stripe, then returns to your site.
  • WooCommerce — creates a Woo order/fee so you can use any Woo gateway.
  • Amount logic — fixed deposit, sum of selected services, or services with fixed fallback.
Test before going live

Run a full book → pay → return → admin status update on a staging site with test keys.

Email & SMS

  • WordPress mail — admin notification; optional customer confirmation (Form & Emails).
  • SMS (Vonage / Nexmo) — staff phone alert; balance checked when saving keys.

CRM & automation

HubSpot

Create/update contacts; optional deals from bookings.

Mailchimp

Add guests to an audience list.

n8n / Zapier / Make

Webhook on pickybooking.booking_created with optional HMAC secret.

Google Calendar

Service-account JSON creates calendar events; optional invite attendees.

Each card in Integrations has a connection strip and test action where available.

AI

  • Providers — Groq (default) or OpenAI.
  • Layout draft — generate a starting floor plan from a text prompt.
  • Copy helpers — service descriptions, form text, element labels.
