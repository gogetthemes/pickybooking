Visual booking maps for WordPress

PickyBooking lets guests pick a real place on a floor plan — seats, tables, desks, courts, rooms — then book date, time, and add-ons. This guide starts with what matters most, then covers every feature.

Read first Layouts · Bookings · Calendar Shortcode [pickybooking]

Edition note

You are reading docs shipped with PickyBooking (free). Payments, SMS, CRM, AI, decorative layers, avatars, and JSON import/export require PickyBooking Pro.

What matters most

If you only have five minutes, do these four things in order.

  1. Create a layout Open Layouts, start blank or import a preset, place bookable items on the map, save.
  2. Set hours & booking rules In Main + Work Days: item labels, exclusive vs capacity, booking horizon, duration and buffer.
  3. Publish the map Paste [pickybooking id="LAYOUT_ID"] on a page (or Elementor / WPBakery). Choose Classic, Smart, Smart Map, or Simple.
  4. Manage bookings Use Bookings and Calendar to confirm or cancel. Optionally enable payments, email/SMS, CRM webhooks.
Important

Empty seats and seats with guest photos use the same tile size. Photos fill the seat and follow its rotation / 3D tilt.
