AI in the layout builder

Use Groq or OpenAI to draft a floor plan and generate copy for services, elements, and form text — then always review before publishing.

How-to Integrations → AI

Pro This guide describes PickyBooking Pro capabilities. They are not included in PickyBooking — see Free vs Pro.

What AI can do

Layout draft

From a text prompt, generate a starting arrangement of bookable items (and helpers). You edit positions, sizes, and IDs after.

Copy helpers

Draft service names/descriptions, element labels, and form/thank-you style text where AI buttons appear in admin.

What AI does not do

It does not set Work Days, take payments, or replace a real floor measurement. Treat output as a draft — verify capacity, IDs, and fire codes yourself.

Step 1 — Connect a provider

  1. Open Integrations PickyBooking → Integrations → AI section.
  2. Choose provider Groq (default, fast) or OpenAI.
  3. Paste API key Groq key or OpenAI key. Keys are stored in picky_settings; leave blank on save to keep the existing secret.
  4. Pick a model Use a listed model for that provider (e.g. Groq meta-llama/llama-4-scout-17b-16e-instruct, OpenAI gpt-4o-mini). Save settings.

Step 2 — Generate a layout draft

  1. Open a layout in the builder Blank canvas or a preset you will replace/adjust.
  2. Open AI Layout Use the AI layout draft control in the builder.
  3. Write a concrete prompt Include industry, approximate counts, and zones. Example: “Wedding ceremony, 40 guest seats in two grids left/right of aisle, bride/groom front, curved front row of 6, labels for Bride’s Family and Groom’s Family.”
  4. Apply & edit Fix overlaps, unify sizes, set custom IDs, bind services, then save.

Prompt tips

  • State counts (“8 tables of 4”, “24 cinema seats in 4 rows”).
  • Name zones you want as Text labels, not bookable items.
  • Mention shapes (square vs circle) if it matters.
  • Avoid vague prompts (“nice restaurant”) — you get generic noise.

Step 3 — AI copy for services / form

  1. Services Library Where AI fill is offered, generate name/description drafts — then set real prices yourself.
  2. Form & Emails Optional AI helpers for thank-you / confirm copy. Keep legal consent text human-written.

When AI fails

  • Missing or invalid API key / wrong provider selected.
  • Model id not allowed for that provider — pick from the dropdown again.
  • Rate limit / quota on Groq or OpenAI — retry later or switch provider.
  • Network blocked from the server — hosting firewall must allow outbound HTTPS to the API.
  • Check browser/network response on the AJAX call (picky_ai nonce / layout draft endpoint).
