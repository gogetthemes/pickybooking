Shortcodes & embeds

Publish any saved layout on a page, post, or builder widget.

Primary shortcode

[pickybooking id="LAYOUT_ID"]

  • id — required. Numeric WordPress post ID of the layout (picky_layout).
  • Copy from the Layouts gallery card or the builder shortcode badge.
  • You can place several shortcodes on one page; each map runs independently.

Page builders

Elementor

Use the Layout Navigator widget in the PickyBooking category. Pick the layout from the control.

WPBakery

Mapped shortcode element with layout ID (and related VC params where registered).

What the shortcode renders

  1. Map canvasItems, walls, labels, icons at builder coordinates.
  2. Wizard UIClassic / Smart / Smart Map / Simple depending on settings.
  3. Booking formDate, time, contacts, services, pay/book CTA.
  4. Account stripWhen registration/avatars features apply.
