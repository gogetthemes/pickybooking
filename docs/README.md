# PickyBooking documentation (HTML)

Documentation for the **free WordPress.org** edition.

## Editions

| Product | Folder | Audience |
|---------|--------|----------|
| **PickyBooking** (this package) | `pickybooking` | Free — core booking |
| **PickyBooking** | `PickyBooking` | Commercial Pro |

See **[Free vs Pro](free-vs-pro.html)**.

Pages marked Pro in the guides (payments, SMS, CRM, AI, avatars, JSON import/export, Elementor) apply only when you upgrade to the commercial plugin.
