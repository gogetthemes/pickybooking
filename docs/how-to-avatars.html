Avatars & accounts

Show guest photos on booked seats, enable WordPress registration, and understand what visitors see when logged out.

How-to Layout appearance

Pro This guide describes PickyBooking Pro capabilities. They are not included in PickyBooking — see Free vs Pro.

What booked avatars do

When enabled, a reserved seat can show the booker’s profile photo filling the same tile as an empty seat (same size, same rotation / 3D tilt). Hover can show a name tip.

Step 1 — Turn avatars on for the layout

  1. Open the layout builder Layouts → edit the map.
  2. Appearance Enable booked avatars (stored as layout meta show_booked_avatars). Save.
  3. Check the public shortcode The map wrapper must expose data-show-booked-avatars="1" (set by the plugin when meta is on).

Step 2 — Who gets a photo

  • Logged-in WordPress users — booking stores _picky_booking_user_id; the map uses their avatar URL (Gravatar / local avatar plugins).
  • Guests without accounts — usually initials / placeholder, or no photo, unless you use demo seeding.
  • Demo sites — PickyBooking can seed demo users with studio portraits for showcase maps (wedding fill, etc.).
Anyone can register

For production avatars from real guests: Settings → General → Anyone can register, and keep the booking account bar so visitors can log in / create an account before booking.

Step 3 — Account bar on the map

  1. Logged out Guests see a login / register CTA but can still book as guest (unless you force accounts via your own theme rules).
  2. Logged in Account strip shows their avatar; new bookings can attach that user for map photos.

Visual rules (already built in)

  • Photo fills the seat tile (not a tiny circle inset).
  • Border radius matches the seat (square radius / circle type).
  • If the seat is rotated or 3D-tilted, the avatar follows the same transform.

Checklist when photos missing

  • Layout appearance: booked avatars = on; layout saved.
  • Booking status is Reserved / blocking occupancy for that slot.
  • Booker is a WP user with an avatar, or demo seed attached a portrait URL.
  • Hard-refresh public page; purge caches.
  • See Troubleshooting for size/rotation quirks.
