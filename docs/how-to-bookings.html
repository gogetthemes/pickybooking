How to handle bookings

Day-to-day ops: find new reservations, confirm or cancel, edit details, and understand orders vs single bookings.

How-to Bookings · Calendar

Where bookings live

Bookings tab

List of all reservations and multi-item orders. Best for inbox-style work and status changes.

Calendar tab

Visual schedule filtered by layout. Best when staff plan a day/week on one venue map.

Statuses (what each means)

StatusMeaningTypical action
Requested Pending confirmation or unpaid hold Call guest / wait for payment → set Reserved, or Cancel
Reserved Confirmed (free or paid) Seat stays blocked for that slot
Canceled Released Seat becomes bookable again
Multi-item orders

When a guest selects several seats, you get a parent order and child bookings. Changing status on the order can cascade to children — confirm in the editor before bulk-cancelling.

Step-by-step: confirm a new booking

  1. Open Bookings PickyBooking → Bookings. New rows may be highlighted until marked seen.
  2. Open the row Check date, time, item ID(s), guest name/phone/email, services, payment state.
  3. Set status to Reserved If payment is required, wait until paid (or confirm manually if you took cash). Status saves with AJAX feedback.
  4. Optional: edit details Correct time, notes, or guest fields in the embedded editor (also available from Calendar).

Cancel a booking

  1. Open the booking or order From Bookings or Calendar.
  2. Set status to Canceled The seat frees for that slot (after buffers still apply for nearby times).
  3. Refunds If paid via Stripe/Woo, refund in that provider’s dashboard — PickyBooking status does not auto-refund.

Use the Calendar

  1. Filter by layout Pick the venue map you are staffing today.
  2. Click a booking Editor opens without leaving the calendar.
  3. Change status inline Same Requested / Reserved / Canceled flow as the list.

What guests see after you change status

  • Reserved — seat stays unavailable for overlapping times; avatar may show if enabled and guest is a WP user / demo avatar.
  • Canceled — seat returns to the pool for new bookings.
  • Requested — usually still blocks the slot so double-booking does not happen while you decide.
